# Betaflight version sweep

The [sweep report](../virtuals/physics/flight_controllers/courbet/betaflight/version_sweep/README.md)
contains the six-release matrix, measured times, version-specific fixes and commands.
All six releases completed the hardware-driver flight, landing and disarm.
Per-version folders contain the firmware, runtime configuration and a short README.

See the [hardware guide](BetaflightHardwareRehosting.md) for the original default
profile, setup and live flight viewer.
