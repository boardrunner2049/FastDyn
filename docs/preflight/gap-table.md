## Enforced stop conditions

- Unknown/ambiguous ISA or mode: reject publication.
- Phase-one image without an origin map: reject publication.
- Existing destination: do not overwrite.
- Phase-one image, origin, memory or optimization-report hash mismatch: reject.
- Cortex-M rewrite outside a registered exact rule and its declared effect/reference contract: retain the identity image and report the exact backend/effect/reference blocker.
- Phase two only: unresolved patch anchor or anchor without exact origin coverage: reject candidate.
- Phase two only: image, plan, bindings, instrumentation, device or bundle hash mismatch: reject.
- Phase two only: unknown trace vocabulary is `unsupported`; malformed identity is `unknown`; an ordered observation mismatch is `counterexample`.

Profitability, timeout, unsupported input and semantic mismatch remain distinct;
none is collapsed into “optimization failed.”
