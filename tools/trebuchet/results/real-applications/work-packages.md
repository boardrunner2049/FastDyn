# Trebuchet work-package ledger

An ordinary release-image Pye training edit passed its fully warm gate in the initial smoke run. The application returned the expected 166 bytes and eight lines, QEMU exited normally, and the cache appended zero translations. The operational window was 7.693357 ms in that single queued-UART replay. In the subsequent joint-image attempt, both images again returned the expected document. The original image appended three translations after its two inventory sweeps, while the FirmBOLT image appended zero. The joint attempt stopped before ranking. These single runs are qualification observations. An improvement over the frozen pre-change deployment requires an independent paired comparison and a completed final campaign. ## Reproduce the correctness checks

From the FastDyn root with the scopt Python environment installed, run the following command. With the pinned native executable configured for the real LLVM layout test, 175 tests passed and 19 historical-fixture cases skipped. Fixtures and mocked trial values have no performance weight.

```sh
SCOPT_LLVM_LAYOUT_BRIDGE=/workspace/trebuchet-work/native/bridge/build/bin/scopt-native \
scopt-env/bin/python -m pytest -q tools/trebuchet/tests \
  tools/scopt/tests/unit/test_{pass_policy,b3_llvm_layout,llvm_layout,general_chain_reuse,region_cleanup,global_values,native_caller_rewrite,wp21_b3_passes}.py
```
