# Pye incremental training comparisons

Each worker measured the original release image editing the upstream package manifest. Every scored block began from a fresh copy of the same sealed training inventory for that arm. A returned document had to match the complete expected UTF-8 bytes. Cache proofs record late translations over the whole launch. The tables give median paired gains in editor latency with exploratory 95% paired-block bootstrap intervals. A gain above one means the candidate completed the edit sooner. Intervals use 12 scored blocks per worker. An independent discarded block preceded them. [Protocol and audit procedure](../../../applications/pye/training-contrasts.md)
