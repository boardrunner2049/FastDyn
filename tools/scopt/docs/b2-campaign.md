# F-B2-7 campaign: preparation, freeze, check, timing (WP15C)

Design: `design/B1-design.md` §7 F-B2-7, §4.8; plan WP15 ("No retuning after
looking at final inputs. The candidate and profile sha256 values are frozen in
the campaign file before timing").

| piece | file |
|---|---|
| preparation chain (snapshot, profile, candidates, V1-V10) | `tests/qemu/b2_prep.py` |
| freeze / check / run | `tests/qemu/b2_campaign.py` |
| the frozen campaign | `campaigns/b2-freertos.toml` (generated by `freeze`, never edited) |
| unit tests (checker, derived campaigns, rules) | `tests/unit/test_wp15c_campaign.py` |

## 1. Preparation (`b2_prep.py`)

```
b2_prep.py --workload compute --out runs/b2/compute     # primary, icount
b2_prep.py --workload blinky  --out runs/b2/blinky      # secondary, informational
```

`prepare` (compute: train-1, train-2, train-3; the first is the cold run, the
others capture-on warm runs appending to the same cache) -> `bundle identity` /
`runtime-identity` -> `import` -> `profile run --phase steady@<window marker>
--reps 3` on every train input (compute marker `0x2990` = `vComputeWindowStart`,
blinky `0x3018` = `prvQueueReceiveTask` entry) -> `profile check` ->
`optimize --pipeline identity` -> `optimize --pipeline b2-layout` and
`--disable P` for each B2 pass -> `validate A` (V1-V9, MANIFEST) ->
`validate A --dynamic` (V10; compute: the three held-out inputs; blinky: the
fixed input) -> `report`. Held-out inputs are used only for V10; final inputs
are never used. Result: `OUT/prep_summary.json`.

## 2. Freeze (`b2_campaign.py freeze`)

Run on a clean, committed tree. It refuses when a prep failed, when the code
to be frozen has uncommitted changes, or when any `run*.json` under `runs/b2`
already names a final input. It writes every identity the timing deploys or
depends on (QEMU, plugin, firmware sha256 + size + mtime, base TOML, snapshot,
profile, every artifact's `cache.sc` sparse sha256 + `MANIFEST.sha256` + id,
every input + split manifest) and the git ids of the `scopt` package,
`pipelines/` and the driver. The file is committed right after.

Arms per workload: `nocache`, `empty`, `warm` (the snapshot the candidates
were optimized from), `identity`, `layout`, `layout-no-cluster-hot`,
`layout-no-order-cold`. `layout-no-hotcold-partition` is built and validated
but excluded from timing (`excluded_arm`, reported as a `not_run` row): it is
degenerate (0 units moved, `cache.sc` byte-identical to warm and identity).

Sets: `compute-heldout`, `compute-final` (3 inputs each, 30 repetitions: 90
samples per arm), `blinky-fixed` (30 repetitions). Train inputs are profile-only.

## 3. Check (`b2_campaign.py check`)

```
b2_campaign.py check --campaign campaigns/b2-freertos.toml --expect-sha256 <hex>
```

Recomputes every frozen value and lists each mismatch; exit 1 on any. It also
requires the campaign file to be committed and clean and the `scopt` package,
`pipelines/` and the driver at HEAD to equal the frozen git ids with no
uncommitted changes, so the code that times is the code that was frozen.

## 4. Timing (`b2_campaign.py run`)

```
b2_campaign.py run --campaign campaigns/b2-freertos.toml --expect-sha256 <hex> \
                   --out-root runs/b2/timing
```

`check`, then per set: `OUT_ROOT/campaigns/<set>.toml` (a `scopt run` campaign
with every deploy arm's frozen sha256; `scopt run` re-checks them in preflight
and after the last run), `scopt run --campaign ... --out OUT_ROOT/<set>`,
`scopt report OUT_ROOT/<set> --profile P`; then `check` again, a combined
`scopt report` (`OUT_ROOT/report/`) and `OUT_ROOT/b2_campaign.json` with the
rules R1-R5 per set. A set directory that already exists is refused.
`--smoke --reps N` is the only way to change the repetitions; it refuses the
final split and writes `smoke.json`.

Rules (also in the campaign file): R1 freeze holds, R2 >= 30 valid pairs per
arm vs warm, R3 no output mismatch, R4 one QEMU sha256, R5 reports rendered.
F-B2-7 is `measured_and_reported` when R1-R5 hold. The speedup direction is
not a pass criterion: a null or negative result is reported as it is.
